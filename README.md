## 📦 Come iniziare

### Prerequisiti
- Node.js (o Bun)
- npm/yarn/pnpm/bun

### Installazione

```bash
# Clona il repository
git clone https://github.com/Danielepalma/sea-bound-portfolio.git

# Entra nella directory
cd sea-bound-portfolio

# Installa le dipendenze
bun install
# o con npm: npm install
```

### Sviluppo locale

```bash
# Avvia il server di sviluppo
bun run dev
# o con npm: npm run dev
```

Il sito sarà disponibile su `http://localhost:5173`

### Build per la produzione

```bash
bun run build
# o con npm: npm run build
```
